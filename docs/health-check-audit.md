# 資產風險健檢修正紀錄

## 確認並修正

- 壓力情境 tooltip 原先未傳入 findings，永遠顯示「未觸發」。各情境現在直接提供 findings 與 interpretation，並同時保留淨資產、質押及回撤警示。
- 目前持倉與加碼草稿的完整性分開檢查。草稿只有價位、沒有股數時，明列未完成草稿，不把目前集中度改為資料不足。真正的持倉缺漏仍有提示，不遮蓋已確認的高風險。
- 狀態徽章與說明改用同一份未截斷風險清單。前三大沿用原卡片75%／90%門檻（至少三個現有標的）；重壓回撤沿用卡片30%／50%門檻。補上低流動性資產、流動比率與現金覆蓋率對應說明。
- 加碼專用、尚無市值的部位，不計入現有標的數與集中度排名。
- TPE/TWSE/TPEX 前綴與台股 .TW/.TWO 後綴標準化，避免同一代號未合併，或00631L未套用指定情境跌幅。其他海外市場前綴不會任意刪除。
- 壓力後淨資產非正：曝險倍數改為null／無法計算，不再輸出99倍。壓力前淨資產非正：回撤百分比改為null／不適用，不偽造100%。
- 真實零值、負值月度淨資產不再從歷史回撤刪除；非有限數值不當成零，首月非正時不計算變動百分比。
- 浮點數誤差不會把正好180%的估算維持率判成低於180%。
- 原先未呈現的dataNotes現在列於「資料檢查與計算限制」，包含缺漏位置及加碼資金假設。

## 沒有變動／模型限制

- 未修改私人試算表、登錄資產、負債、報價、持股數量或登入方式。
- 未重新校準五組市場跌幅與00631L各情境跌幅。2000／2008為指定假設，不宣稱該ETF在當時存在或具有真實歷史跌幅。
- 質押維持率仍是全部證券市值／質押借款的估算；缺少實際質押清單與契約，不能當成券商正式維持率。
- 流動比率仍用非房貸負債估算，未提供負債期限，不能冒稱完整一年內到期負債。
- 加碼模擬假設現有現金轉成證券、淨資產不變；未建模借款或外部入金，超過現金時會提示。
- 地域分類依登錄區域，未穿透ETF底層；只支援目前網站的非負市值與多頭曝險模型，並非空頭、衍生性商品或完整家庭現金流模型。
